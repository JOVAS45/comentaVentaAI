## 1. Problema

ComentaVenta IA es una aplicación para vendedores que transmiten por TikTok Live. Clasifica cada comentario del chat en una de 5 clases (Pedido, Pregunta, Pago y envío, Objeción, Otros) para que el vendedor pueda atender a tiempo pedidos y preguntas, y no perder ventas por volumen de comentarios.
